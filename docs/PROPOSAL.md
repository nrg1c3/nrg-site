# مقترح موقع NRG — للمراجعة (مفيش بناء قبل الموافقة)

## 1) هيكل الملفات
```
/
├─ index.html            ← العربي (RTL) — صفحة واحدة بأقسام
├─ en/index.html         ← الإنجليزي (LTR) — نفس الأقسام
├─ 404.html              ← صفحة خطأ بسيطة باللغتين
├─ assets/
│  ├─ css/tokens.css     ← الألوان والخطوط والمسافات
│  ├─ css/main.css       ← التصميم (خصائص منطقية، موبايل الأول)
│  ├─ js/main.js         ← قايمة الموبايل فقط (أقل من 1KB، الموقع يشتغل من غيره)
│  ├─ fonts/             ← خطوط محلية woff2
│  └─ img/               ← لوجو NRG + لوجوهات/صور المشاريع (SVG/WebP)
├─ .nojekyll
├─ robots.txt, sitemap.xml
├─ CNAME                 ← لاحقًا لما الدومين يجهز
└─ docs/ (PROPOSAL.md, CONTENT-TODO.md)
```
**ليه صفحة واحدة؟** 4 أقسام بمحتوى قليل → صفحة واحدة بأنكورز أسرع على الموبايل وأسهل في الصيانة. لو بعدين كل مشروع احتاج تفاصيل، نضيف `/projects/wasl/` إلخ.

## 2) ترتيب الصفحة
1. **الهيدر** (ثابت): لوجو NRG · روابط الأقسام · زرار `EN`/`ع` · زرار واتساب. على الموبايل: قايمة ☰.
2. **الواجهة (Hero)**: سطر تعريفي قصير «تطبيقات · أتمتة · ذكاء اصطناعي» + زرارين: «كلمنا على واتساب» و«شوف مشاريعنا». خلفية شبكة/خطوط هادية (CSS/SVG، مش صورة تقيلة).
3. **مين إحنا**: فقرة قصيرة + 3 نقاط عن طريقة الشغل. ملاحظة صغيرة: «للتشغيل والإدارة: C3» مع لينك (لما يتوفر).
4. **مشاريعنا**: 4 كروت (عمود واحد موبايل ← 2 تابلت ← 4 أو 2×2 ديسكتوب). كل كارت: أيقونة/لوجو · الاسم · سطر وصف · وسم الحالة (مثلاً «قيد التطوير» — **لو المستخدم أكدها**) · لينك لو موجود.
5. **خدماتنا**: 3 كروت: تطبيقات · أتمتة · وكلاء AI للشركات — كل واحد سطرين + أمثلة.
6. **تواصل**: زرار واتساب كبير برسالة جاهزة (`wa.me/201508917780?text=…`) + الرقم مكتوب.
7. **الفوتر**: © NRG · رابط C3 · تبديل اللغة.

**مش هنحط**: أرقام/عدادات، شعارات عملاء، آراء، فريق — لحد ما يتوفر محتوى حقيقي.

## 3) التصميم
- **الطابع**: داكن تقني أساسًا (مع وضع فاتح تلقائي)، نظيف، مسافات واسعة، حدود رفيعة، لمسة توهج خفيفة على الكروت.
- **الألوان (مبدئية لحد ما توصل هوية NRG)**:
  - خلفية `#0B0F17` · سطح `#121826` · نص `#E6EAF2` · نص ثانوي `#9AA4B5`
  - لون أساسي (Accent) سماوي كهربائي `#3BC9F5` + ثانوي بنفسجي `#7C5CFF` للتدرج
  - واتساب أخضر `#25D366` للزرار ده بس
- **الخطوط**: عربي **IBM Plex Sans Arabic** (تقني ومقروء)، إنجليزي **Inter** أو IBM Plex Sans، أرقام وكود **JetBrains Mono** للمسات صغيرة. كلهم مفتوحين ومستضافين محليًا.
- **الحركة**: ظهور ناعم للأقسام عند السكرول، بتتلغي مع `prefers-reduced-motion`.
- **الإتاحة**: تباين AA، تنقل كيبورد، `alt`، أزرار ≥44px.

## 4) قرارات محتاجة موافقتك
1. صفحة واحدة بأقسام (مقترح) ولا صفحات منفصلة لكل مشروع من الأول؟
2. الطابع الداكن والألوان دي، ولا عندكم هوية/لوجو جاهز نمشي عليه؟
3. العربي فصحى مبسطة (مقترح) ولا عامية مصرية؟
4. «سايفو»: الاسم ده نهائي؟ (عندي إشارات لمشروع صوتي اسمه «سندي» — هل ده نفسه ولا مختلف؟ مش هفترض.)
